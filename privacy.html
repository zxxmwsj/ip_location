OVERVIEW

隐私政策概述

感谢你使用 Atlas。我们尽量保持服务简单：页面本身不要求注册，也不建立用户账户。使用本服务即表示你理解查询请求会发送给第三方 IP 数据服务，以便生成结果。

WHAT IS PROCESSED

信息处理

你主动输入的 IP

当你输入一个 IP 地址进行查询时，该地址会由浏览器发送至 IPinfo.io，以返回国家、地区、城市、运营商、坐标和时区等信息。

当前公网 IP

当你点击“定位我的 IP”时，页面会调用第三方服务的当前 IP 接口来获取你的公网地址，再查询对应信息。

基础技术信息

浏览器、网络服务商和第三方 API 可能按照各自的服务政策处理请求时间、网络地址、设备和日志等基础技术信息。

HOW IT IS USED

信息如何使用

  • 生成你请求的 IP 归属地查询结果。
  • 维护接口稳定性、识别异常请求并防止滥用。
  • 改进页面可用性和服务性能。

THIRD PARTY

第三方服务

Atlas 使用 IPinfo.io 提供 IP 地理位置数据。查询请求可能受到该服务的速率限制、可用性和隐私政策约束。

重要提示：Atlas 不控制第三方服务如何保留或处理其收到的请求，请在使用前阅读 IPinfo.io 的相关条款和隐私政策。

YOUR CONTROL

你的选择

  • 你可以随时停止使用本网站。
  • 你可以通过浏览器设置清理缓存、本地存储和站点数据。
  • 如果你不希望 IP 被发送至第三方服务，请不要提交查询请求。

UPDATES

政策更新

当服务功能、数据处理方式或适用要求发生变化时，我们可能更新本页面。更新后的版本会在此页面展示新的更新时间。
