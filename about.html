ABOUT ATLAS № 02

把网络坐标，
讲得更清楚。

Atlas 是一个轻量的 IP 归属地查询工具，把分散的网络数据整理成直观、易读的结果。

THE IDEA

项目简介

无论你是网络管理员、开发者，还是只是想知道自己的公网出口在哪里，Atlas 都希望用尽可能少的步骤给你一份清晰的答案。

我们关注的是“网络上下文”——一个 IP 所在的国家、城市、运营商、组织、时区和坐标，而不是把定位结果包装成绝对精确的位置。

WHAT IT DOES

核心能力

查询

IP 地址查询

支持输入 IPv4 地址，返回国家、地区、城市等归属地信息。

本机

查询我的 IP

一键读取当前公网 IP，快速了解当前网络出口。

地图

地图定位

通过经纬度打开地图查看空间上下文。

网络

网络信息

展示 ISP、组织和 AS 信息，帮助理解 IP 的网络归属。

时区

时区信息

显示 IP 关联地区的时区，方便跨地区沟通和测试。

快速

原生前端

基于 HTML、CSS 与 JavaScript 构建，页面轻量、加载快速。

GOOD USE CASES

适用场景

  • 网络排查 — 了解一个公网 IP 的运营商和大致网络位置。
  • 开发测试 — 验证地理位置、时区和 IP 相关功能。
  • 安全分析 — 为可疑 IP 提供初步的网络上下文。
  • 日常查看 — 快速确认自己当前的公网出口。

TECH NOTES

技术说明

  • 前端：HTML5、CSS3 和原生 JavaScript。
  • 数据：使用 IPinfo.io 提供的 IP 数据服务。
  • 部署：适合部署到 Cloudflare Pages 等静态托管平台。
  • 隐私：本项目不建立查询历史记录，查询请求会发送至第三方数据服务。

BOUNDARIES

使用边界

  • IP 定位通常只能反映城市、运营商或网络节点，不代表真实物理位置。
  • 代理、VPN、移动网络和企业网络可能导致结果与实际位置不同。
  • 请勿将查询结果用于非法目的，也不要据此对个人作出高风险判断。
